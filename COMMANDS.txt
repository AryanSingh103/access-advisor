ACCESSADVISOR — COPY/PASTE COMMANDS

Every command below uses absolute paths, so it works no matter what
directory your shell is currently sitting in. There are no "#" comments
inline with commands — your zsh isn't configured with interactive_comments,
so a pasted "command # comment" gets the comment fed to the command as a
literal argument instead of being ignored. Only paste the actual command
lines, not the ── header ── lines.

IMPORTANT: the system `python3` does NOT have the backend deps installed.
The working Python env is at /Users/aryan/micromamba/bin/python3 (3.9.21).
Every backend command below uses that full path on purpose — don't swap in
plain `python3`/`pip3` or it'll look broken.

NOTE: your backend (port 8000) and frontend (port 3000) are usually already
running in the background from an earlier session. "Address already in use"
when starting uvicorn just means it's already up — check with the commands
below before trying to start a second copy.
